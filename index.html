  • Program memproses beberapa paket secara berurutan dan menampilkan rincian biaya per paket serta laporan rekapitulasi akhir (jumlah paket per zona, jenis layanan, total berat, penggunaan berat volumetrik, total asuransi, total pendapatan, dan paket dengan biaya tertinggi).
IPO

Input – Process – Output

Input: Nomor paket, berat aktual, panjang, lebar, tinggi, zona tujuan, jenis pelayanan, nilai barang, dan pilihan asuransi.

Process: Menghitung berat volumetrik = (panjang x lebar x tinggi) / 6.000. Menentukan berat tagihan (nilai maksimum antara berat aktual dan berat volumetrik, dibulatkan ke atas). Menghitung biaya dasar (berat tagihan x tarif zona). Menghitung biaya tambahan layanan (jika prioritas, ditambah 40%). Menghitung biaya asuransi (1% dari nilai barang, min. Rp5.000 jika asuransi dipilih). Menghitung total biaya per paket dan mengakumulasi data untuk rekapitulasi (jumlah paket per zona, jenis layanan, total berat, jumlah paket dengan berat volumetrik, total asuransi, total pendapatan, dan identifikasi biaya tertinggi).

Output: Rincian biaya per paket serta laporan rekapitulasi pengiriman keseluruhan.

Algoritma deskriptif

  1. Menerima masukan dari pengguna secara berurutan: Nilai barang (nilai_barang) Nomor paket (nomor_paket) Berat aktual (Berat_aktual) Panjang (panjang), lebar (lebar), dan tinggi (tinggi) paket Zona tujuan (zona_tujuan: A, B, atau C) Jenis pelayanan (jenis_pelayanan: 1 untuk Reguler, 2 untuk Prioritas) Pilihan asuransi (Pilihan_asuransi: Y atau N)
  2. Menghitung berat Volumetrik dengan rumus: (panjang × lebar × tinggi) / 6000
  3. Menentukan berat tagihan: Membandingkan berat aktual dengan berat volumetrik, lalu ambil nilai yang paling besar (berat_maksimal). Membulatkan berat_maksimal ke atas menjadi bilangan bulat (berat_tagihan).
  4. Menentukan tarif per kilogram berdasarkan zona tujuan (huruf diubah menjadi kapital terlebih dahulu): Jika zona tujuan adalah 'A', maka tarif per kg = 8.000. Jika zona tujuan adalah 'B', maka tarif per kg = 12.000. Jika zona tujuan adalah 'C', maka tarif per kg = 18.000. Jika zona selain A, B, atau C, tampilkan pesan "Zona tujuan tidak valid!" lalu hentikan program.
  5. Menghitung biaya dasar: berat_tagihan x tarif_per_kg
  6. Menghitung biaya tambahan berdasarkan jenis pelayanan:Jika jenis pelayanan adalah 2 (Prioritas), maka biaya tambahan = 40% dari biaya dasar.Jika jenis pelayanan adalah 1 (Reguler), maka biaya tambahan = 0.Jika jenis pelayanan di luar angka tersebut, tampilkan pesan "Jenis pelayanan tidak valid!" lalu hentikan program.
  7. Menghitung biaya asuransi:Jika pilihan asuransi adalah 'Y' (ya), maka hitung biaya asuransi sebesar 1% dari nilai barang.Jika hasil perhitungan biaya asuransi kurang dari 5.000, maka tetapkan biaya asuransi menjadi minimal 5.000.Jika selain 'Y', biaya asuransi = 0.
  8. Menghitung total biaya pengiriman dengan menjumlahkan biaya dasar, biaya tambahan, dan biaya asuransi.
  9. Menampilkan hasil keluaran ke layar yang mencakup nomor paket, rincian biaya (dasar, tambahan, dan asuransi), serta total biaya akhir.
  10. Menahan layar dengan perintah tunggu hingga pengguna menekan tombol Enter sebelum program selesai.

Input Data Menerima berbagai parameter dari pengguna seperti nilai barang, nomor resi/paket, berat asli, dimensi ukuran (panjang, lebar, tinggi), zona tujuan (A, B, atau C), jenis layanan (1 atau 2), dan persetujuan asuransi (Y atau N).

Perhitungan Berat Volumetrik: Panjang x Lebar x Tinggi / 6000

Penentuan Berat Tagihan (berat_tagihan) Program membandingkan antara berat aktual timbangan dengan berat volumetrik menggunakan max(). Hasil yang lebih besar akan dibulatkan ke atas menggunakan fungsi ceil(). Misalnya, hasil berat 2.1 kg akan dibulatkan menjadi 3 kg.

Penentuan Tarif Zona (tarif_per_kg) Tarif dasar per kilogram disesuaikan dengan zona tujuan: Zona A: Rp 8.000 / kg Zona B: Rp 12.000 / kg Zona C: Rp 18.000 / kg

Jika zona di luar huruf tersebut, program akan menampilkan pesan kesalahan dan berhenti (return 1).

Biaya Tambahan Pelayanan Jika memilih layanan reguler (1), tidak ada tambahan biaya (0). Jika memilih layanan prioritas (2), dikenakan biaya tambahan sebesar 40% dari total biaya dasar.

Biaya Asuransi Jika pengguna memilih Y, dihitung 1% dari total nilai barang. Terdapat aturan batas bawah (minimum), jika hasil 1% kurang dari Rp 5.000, maka biaya asuransi otomatis ditetapkan menjadi Rp 5.000.

// Data rekapitulasi (Modul B)
struct RekapPengiriman {
    int zonaA = 0;
    int zonaB = 0;
    int zonaC = 0;
    int reguler = 0;
    int prioritas = 0;
    int menggunakanBeratVolumetrik = 0;
    double totalBeratAktual = 0;
    double totalBeratTagihan = 0;
    double totalAsuransi = 0;
    double totalPendapatan = 0;
    double biayaTertinggi = -1;
    string nomorPaketBiayaTertinggi = "-";
};

// Hasil perhitungan satu paket (keluaran Modul A)
struct HasilPaket {
    string nomorPaket;
    char zona;
    int jenisPelayanan;
    double beratAktual;
    double beratVolumetrik;
    double beratTagihan;
    double biayaAsuransi;
    double totalBiaya;
};

// Memperbarui rekapitulasi dengan data satu paket
void perbaruiRekap(RekapPengiriman &rekap, const HasilPaket &paket) {
    if (paket.zona == 'A') ++rekap.zonaA;
    else if (paket.zona == 'B') ++rekap.zonaB;
    else ++rekap.zonaC;

    if (paket.jenisPelayanan == 1) ++rekap.reguler;
    else ++rekap.prioritas;

    if (paket.beratVolumetrik > paket.beratAktual) {
        ++rekap.menggunakanBeratVolumetrik;
    }

    rekap.totalBeratAktual += paket.beratAktual;
    rekap.totalBeratTagihan += paket.beratTagihan;
    rekap.totalAsuransi += paket.biayaAsuransi;
    rekap.totalPendapatan += paket.totalBiaya;

    if (paket.totalBiaya > rekap.biayaTertinggi) {
        rekap.biayaTertinggi = paket.totalBiaya;
        rekap.nomorPaketBiayaTertinggi = paket.nomorPaket;
    }
}

// Menampilkan laporan rekapitulasi
void tampilkanRekapitulasi(const RekapPengiriman &rekap) {
    cout << "\n========== REKAPITULASI PENGIRIMAN ==========" << endl;
    cout << "Jumlah paket zona A: " << rekap.zonaA << endl;
    cout << "Jumlah paket zona B: " << rekap.zonaB << endl;
    cout << "Jumlah paket zona C: " << rekap.zonaC << endl;
    cout << "Jumlah paket reguler: " << rekap.reguler << endl;
    cout << "Jumlah paket prioritas: " << rekap.prioritas << endl;
    cout << "Total berat aktual: " << rekap.totalBeratAktual << " kg" << endl;
    cout << "Total berat tagihan: " << rekap.totalBeratTagihan << " kg" << endl;
    cout << "Paket menggunakan berat volumetrik: "
         << rekap.menggunakanBeratVolumetrik << endl;
    cout << "Total asuransi: Rp " << rekap.totalAsuransi << endl;
    cout << "Total pendapatan: Rp " << rekap.totalPendapatan << endl;
    cout << "Paket dengan biaya tertinggi: " << rekap.nomorPaketBiayaTertinggi
         << " (Rp " << rekap.biayaTertinggi << ")" << endl;
}

        cout << "Apakah ingin menggunakan asuransi? (Y/N): ";

            cerr << "Pilihan asuransi tidak valid." << endl;
            return 1;
        }
        pilihan_asuransi = static_cast(toupper(static_cast(pilihan_asuransi)));
        if (pilihan_asuransi != 'Y' && pilihan_asuransi != 'N') {
            cerr << "Pilihan asuransi harus Y atau N." << endl;
            return 1;
        }

        // Modul A: perhitungan biaya
        const double berat_volumetrik = (panjang * lebar * tinggi) / 6000;
        const double berat_tagihan = ceil(max(berat_aktual, berat_volumetrik) - 1e-9);
        const double biaya_dasar = berat_tagihan * tarif_per_kg;
        const double biaya_tambahan = (jenis_pelayanan == 2) ? 0.40 * biaya_dasar : 0;
        double biaya_asuransi = 0;
        if (pilihan_asuransi == 'Y') {
            biaya_asuransi = max(0.01 * nilai_barang, 5000.0);
        }
        const double total_biaya = biaya_dasar + biaya_tambahan + biaya_asuransi;

        // Modul B: perbarui rekapitulasi
        HasilPaket paket = {nomor_paket, zona_tujuan, jenis_pelayanan,
                            berat_aktual, berat_volumetrik, berat_tagihan,
                            biaya_asuransi, total_biaya};
        perbaruiRekap(rekap, paket);

        cout << "\n--- Rincian Biaya Paket " << nomor_paket << " ---" << endl;
        cout << "Zona tujuan: " << zona_tujuan << endl;
        cout << "Berat volumetrik: " << berat_volumetrik << " kg" << endl;
        cout << "Berat tagihan: " << berat_tagihan << " kg" << endl;
        cout << "Biaya dasar: Rp " << biaya_dasar << endl;
        cout << "Biaya tambahan pelayanan: Rp " << biaya_tambahan << endl;
        cout << "Biaya asuransi: Rp " << biaya_asuransi << endl;
        cout << "Total biaya: Rp " << total_biaya << endl;
    }

    // Modul B: tampilkan hasil akhir
    tampilkanRekapitulasi(rekap);

    return 0;
}

Fungsi

  • perbaruiRekap(rekap, paket): menambahkan satu paket ke rekap (rekap dikirim sebagai referensi &, paket sebagai const &).
  • tampilkanRekapitulasi(rekap): mencetak laporan akhir.
  • main(): membaca masukan, menghitung biaya (Modul A), lalu memanggil kedua fungsi di atas.
  • Fungsi bawaan: ceil() membulatkan ke atas, max() memilih nilai terbesar, isfinite() memeriksa angka valid, toupper() mengubah ke huruf besar.

Proses integrasi

Proses Integrasi Modul A dan Modul B

Integrasi dilakukan dengan menggabungkan proses perhitungan biaya pengiriman dan rekapitulasi ke dalam satu program.

  1. Modul A — Proses Utama

    Menerima dan memvalidasi data paket, kemudian menghitung berat tagihan, biaya dasar, tambahan layanan prioritas, biaya asuransi, dan total biaya pengiriman.

    Setelah paket terakhir diproses, program menampilkan rincian biaya setiap paket dan laporan rekapitulasi keseluruhan dalam satu program tanpa perlu menjalankan Modul A dan Modul B secara terpisah.

Tantangan Logika Kondisi dan Validasi Input

Penjelasan tambahan

Salah satu bagian yang cukup sulit adalah menentukan tarif zona dan jenis pelayanan menggunakan rantai if / else if / else. Sering muncul kebingungan dalam menentukan kondisi yang harus dipenuhi, kapan program harus dihentikan menggunakan return 1, dan kapan program masih boleh melanjutkan proses.

Selain itu, input berupa huruf kecil terkadang terlupakan dalam proses validasi. Misalnya, pengguna memasukkan a untuk zona atau y untuk asuransi, sedangkan program hanya memeriksa huruf kapital. Untuk mengatasi masalah tersebut, fungsi toupper() digunakan untuk mengubah karakter menjadi huruf kapital sebelum dilakukan pemeriksaan.

1. Rantai if / else if / else

Setiap kondisi harus disusun dengan urutan yang tepat. Jika zona A, B, atau C ditemukan, program menetapkan tarif yang sesuai. Jika tidak ada kondisi yang cocok, program menampilkan pesan kesalahan.

2. Menentukan penggunaan return 1

return 1 digunakan untuk mengakhiri program dengan status kegagalan ketika input tidak valid dan program memang dirancang untuk berhenti. Jika input valid, program dapat melanjutkan ke proses perhitungan berikutnya.

3. Mengatasi input huruf kecil

Fungsi toupper() membantu menyamakan karakter huruf kecil dan kapital sebelum validasi, sehingga input seperti a dan A dapat diperlakukan secara konsisten.
