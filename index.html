02 · Analisis Masalah

Memahami masalah sebelum membangun solusi

Konteks

Latar belakang dan rumusan masalah

Latar belakang: Situasi dan kebutuhan yang mendasari pembuatan program ini adalah kondisi operasional di perusahaan jasa ekspedisi atau pengiriman barang yang sering kali menghadapi kompleksitas dalam menentukan tarif secara cepat, dan konsisten.

Rumusan masalah: Masalah utama yang ingin diselesaikan adalah ketiadaan sistem otomatis untuk menghitung biaya pengiriman paket secara akurat (berdasarkan berat, dimensi, zona, layanan, dan asuransi) sekaligus mengelola rekapitulasi data operasional pengiriman secara menyeluruh.

Sasaran

Tujuan dan pengguna program

Tujuan: Mengotomatisasi proses perhitungan biaya pengiriman paket secara akurat berdasarkan berat, dimensi, zona, layanan, dan asuransi, serta menghasilkan rekapitulasi data operasional pengiriman secara menyeluruh.

Pengguna: Petugas/operator ekspedisi atau perusahaan jasa pengiriman barang yang membutuhkan alat bantu hitung tarif cepat dan manajemen laporan rekapitulasi pengiriman harian.

Ruang lingkup

Ketentuan dan batasan

  • Program memproses beberapa paket secara berurutan dan menampilkan rincian biaya per paket serta laporan rekapitulasi akhir (jumlah paket per zona, jenis layanan, total berat, penggunaan berat volumetrik, total asuransi, total pendapatan, dan paket dengan biaya tertinggi).
IPO

Input – Process – Output

Input: Nomor paket, berat aktual, panjang, lebar, tinggi, zona tujuan, jenis pelayanan, nilai barang, dan pilihan asuransi.

Process: Menghitung berat volumetrik = (panjang x lebar x tinggi) / 6.000. Menentukan berat tagihan (nilai maksimum antara berat aktual dan berat volumetrik, dibulatkan ke atas). Menghitung biaya dasar (berat tagihan x tarif zona). Menghitung biaya tambahan layanan (jika prioritas, ditambah 40%). Menghitung biaya asuransi (1% dari nilai barang, min. Rp5.000 jika asuransi dipilih). Menghitung total biaya per paket dan mengakumulasi data untuk rekapitulasi (jumlah paket per zona, jenis layanan, total berat, jumlah paket dengan berat volumetrik, total asuransi, total pendapatan, dan identifikasi biaya tertinggi).

Output: Rincian biaya per paket serta laporan rekapitulasi pengiriman keseluruhan.

Modul A — Proses Utama

Algoritma deskriptif

  1. Menerima masukan dari pengguna secara berurutan: Nilai barang (nilai_barang) Nomor paket (nomor_paket) Berat aktual (Berat_aktual) Panjang (panjang), lebar (lebar), dan tinggi (tinggi) paket Zona tujuan (zona_tujuan: A, B, atau C) Jenis pelayanan (jenis_pelayanan: 1 untuk Reguler, 2 untuk Prioritas) Pilihan asuransi (Pilihan_asuransi: Y atau N)
  2. Menghitung berat Volumetrik dengan rumus: (panjang × lebar × tinggi) / 6000
  3. Menentukan berat tagihan: Membandingkan berat aktual dengan berat volumetrik, lalu ambil nilai yang paling besar (berat_maksimal). Membulatkan berat_maksimal ke atas menjadi bilangan bulat (berat_tagihan).
  4. Menentukan tarif per kilogram berdasarkan zona tujuan (huruf diubah menjadi kapital terlebih dahulu): Jika zona tujuan adalah 'A', maka tarif per kg = 8.000. Jika zona tujuan adalah 'B', maka tarif per kg = 12.000. Jika zona tujuan adalah 'C', maka tarif per kg = 18.000. Jika zona selain A, B, atau C, tampilkan pesan "Zona tujuan tidak valid!" lalu hentikan program.
  5. Menghitung biaya dasar: berat_tagihan x tarif_per_kg
  6. Menghitung biaya tambahan berdasarkan jenis pelayanan:Jika jenis pelayanan adalah 2 (Prioritas), maka biaya tambahan = 40% dari biaya dasar.Jika jenis pelayanan adalah 1 (Reguler), maka biaya tambahan = 0.Jika jenis pelayanan di luar angka tersebut, tampilkan pesan "Jenis pelayanan tidak valid!" lalu hentikan program.
  7. Menghitung biaya asuransi:Jika pilihan asuransi adalah 'Y' (ya), maka hitung biaya asuransi sebesar 1% dari nilai barang.Jika hasil perhitungan biaya asuransi kurang dari 5.000, maka tetapkan biaya asuransi menjadi minimal 5.000.Jika selain 'Y', biaya asuransi = 0.
  8. Menghitung total biaya pengiriman dengan menjumlahkan biaya dasar, biaya tambahan, dan biaya asuransi.
  9. Menampilkan hasil keluaran ke layar yang mencakup nomor paket, rincian biaya (dasar, tambahan, dan asuransi), serta total biaya akhir.
  10. Menahan layar dengan perintah tunggu hingga pengguna menekan tombol Enter sebelum program selesai.

MULAI
  DEKLARASI
    // Variabel Input
    nomor_paket : STRING
    Berat_aktual, panjang, lebar, tinggi, nilai_barang : REAL
    zona_tujuan, Pilihan_asuransi : CHARACTER
    jenis_pelayanan : INTEGER

    // Variabel Proses dan Output
    berat_volumetrik, berat_maksimal, berat_tagihan : REAL
    tarifperKg, biaya_dasar, biaya_tambahan, biaya_asuransi, total_biaya : REAL

ALGORITMA
    // Input Data Pengguna
    Tampilkan "Masukkan nilai Barang (Rp): "
    Baca(nilai_barang)
    
    Tampilkan "Masukkan Nomor Paket: "
    Baca(nomor_paket)
    
    Tampilkan "Masukkan Berat Aktual (kg): "
    Baca(Berat_aktual)
    
    Tampilkan "Masukkan Panjang (cm): "
    Baca(panjang)

    Tampilkan "Masukkan Lebar (cm): "
    Baca(lebar)

    Tampilkan "Masukkan Tinggi (cm): "
    Baca(tinggi)

    Tampilkan "Masukkan Zona_Tujuan (A/B/C): "
    Baca(zona_tujuan)
    
    Tampilkan "Jenis Pelayanan (1. Reguler, 2. Prioritas): "
    Baca(jenis_pelayanan)
    
    Tampilkan "Apakah ingin menggunakan asuransi? (Y/N): "
    Baca(Pilihan_asuransi)

    // Perhitungan Berat Volumetrik dan Berat Tagihan
    berat_volumetrik <- (panjang * lebar * tinggi) / 6000
    berat_maksimal <- MAX(Berat_aktual, berat_volumetrik)
    berat_tagihan <- CEIL(berat_maksimal)

    // Menentukan Tarif per Kg Berdasarkan Zona Tujuan
    tarifperKg <- 0
    zona_tujuan <- TOUPPER(zona_tujuan)
    
    JIKA zona_tujuan == 'A' MAKA
        tarifperKg <- 8000
    SEBALIKNYA JIKA zona_tujuan == 'B' MAKA
        tarifperKg <- 12000
    SEBALIKNYA JIKA zona_tujuan == 'C' MAKA
        tarifperKg <- 18000
    SEBALIKNYA
        Tampilkan "Zona tujuan tidak valid!"
        KELUAR PROGRAM
    AKHIR JIKA

    biaya_dasar <- berat_tagihan * tarifperKg

    // Menghitung biaya tambahan berdasarkan jenis pelayanan
    biaya_tambahan <- 0
    JIKA jenis_pelayanan == 2 MAKA
        biaya_tambahan <- 0.40 * biaya_dasar
    SEBALIKNYA JIKA jenis_pelayanan == 1 MAKA
        biaya_tambahan <- 0
    SEBALIKNYA
        Tampilkan "Jenis pelayanan tidak valid!"
        KELUAR PROGRAM
    AKHIR JIKA

    // Menghitung biaya asuransi jika dipilih
    biaya_asuransi <- 0
    JIKA TOUPPER(Pilihan_asuransi) == 'Y' MAKA
        biaya_asuransi <- 0.01 * nilai_barang
        JIKA biaya_asuransi < 5000 MAKA
            biaya_asuransi <- 5000
        AKHIR JIKA
    AKHIR JIKA

    // Menghitung dan Menampilkan Total Biaya
    Tampilkan "No. paket: ", nomor_paket
    total_biaya <- biaya_dasar + biaya_tambahan + biaya_asuransi
    Tampilkan "Biaya dasar ", biaya_dasar, " + Biaya tambahan ", biaya_tambahan, " + Biaya asuransi ", biaya_asuransi
    Tampilkan "Total Biaya: Rp ", total_biaya
    
    Tampilkan "Tekan Enter untuk keluar...."

Menggunakan bahasa pemrograman C++

1. Library (#include).

#include iostream: Digunakan untuk menangani proses input (cin) dan output (cout).

#include string: Digunakan untuk mengolah tipe data teks (string), seperti nomor_paket.

#include iomanip: Digunakan untuk mengatur format tampilan output (meskipun dalam kode ini tidak banyak terpakai secara langsung).

#include cmath: Digunakan untuk fungsi matematika seperti ceil() yang dipakai untuk pembulatan ke atas pada berat tagihan.

#include algorithm: Digunakan untuk fungsi max() guna membandingkan nilai berat aktual dan berat volumetrik.

#include cctype: Digunakan untuk fungsi manipulasi karakter seperti toupper() untuk mengubah huruf kecil menjadi kapital.

Input Data Menerima berbagai parameter dari pengguna seperti nilai barang, nomor resi/paket, berat asli, dimensi ukuran (panjang, lebar, tinggi), zona tujuan (A, B, atau C), jenis layanan (1 atau 2), dan persetujuan asuransi (Y atau N).

Perhitungan Berat Volumetrik: Panjang x Lebar x Tinggi / 6000

Penentuan Berat Tagihan (berat_tagihan) Program membandingkan antara berat aktual timbangan dengan berat volumetrik menggunakan max(). Hasil yang lebih besar akan dibulatkan ke atas menggunakan fungsi ceil(). Misalnya, hasil berat 2.1 kg akan dibulatkan menjadi 3 kg.

Penentuan Tarif Zona (tarif_per_kg) Tarif dasar per kilogram disesuaikan dengan zona tujuan: Zona A: Rp 8.000 / kg Zona B: Rp 12.000 / kg Zona C: Rp 18.000 / kg

Jika zona di luar huruf tersebut, program akan menampilkan pesan kesalahan dan berhenti (return 1).

Biaya Tambahan Pelayanan Jika memilih layanan reguler (1), tidak ada tambahan biaya (0). Jika memilih layanan prioritas (2), dikenakan biaya tambahan sebesar 40% dari total biaya dasar.

Biaya Asuransi Jika pengguna memilih Y, dihitung 1% dari total nilai barang. Terdapat aturan batas bawah (minimum), jika hasil 1% kurang dari Rp 5.000, maka biaya asuransi otomatis ditetapkan menjadi Rp 5.000.

04 · Modul B

Modul B — Proses Rekapitulasi & Kondisi Akhir

Modul B mengolah hasil perhitungan pengiriman dari Modul A dan menampilkan rekapitulasi seluruh paket.

Perencanaan

Penanggung jawab

Aning Dwi Setyowati-322610002

Algoritma deskriptif

  1. Mulai dan inisialisasi seluruh variabel rekapitulasi dengan nilai awal nol.
  2. Masukkan jumlah paket. Jika jumlah paket kurang dari atau sama dengan nol, tampilkan pesan kesalahan dan akhiri program.
  3. Ambil data setiap paket dan gunakan hasil perhitungan Modul A, meliputi berat tagihan, biaya asuransi, dan total biaya.
  4. Hitung jumlah paket berdasarkan zona A, B, dan C serta layanan reguler dan prioritas.
  5. Akumulasikan berat aktual, berat tagihan, biaya asuransi, dan pendapatan keseluruhan.
  6. Hitung jumlah paket yang menggunakan berat volumetrik dan identifikasi paket dengan biaya tertinggi.
  7. Setelah semua paket diproses, tampilkan seluruh rekapitulasi dan akhiri program.
